## BACKEND APIs TO CREATE

### 1. `app/api/user/profile/route.js`

**GET** – Fetch user profile
- Returns: { id, name, email, phoneNumber, city, selectedCategories, selectedPlatforms, emailNotifications, whatsappNotifications, dailyDigest, digestTime, subscriptionPlan, apiKey, profilePicture, createdAt }

**PUT** – Update profile fields
- Body: { name, phoneNumber, city, selectedCategories, selectedPlatforms, emailNotifications, whatsappNotifications, dailyDigest, digestTime }
- Validate phoneNumber: must be +923XXXXXXXXX format (Pakistan)
- Validate city: must be from cityList
- Validate selectedCategories: must be valid categories
- Save and return updated user

### 2. `app/api/user/password/route.js` (PUT)
- Protected route
- Body: { currentPassword, newPassword }
- Verify current password with bcrypt
- Hash new password and save
- Return success message

### 3. `app/api/user/account/route.js` (DELETE)
- Protected route
- Deletes user account AND all associated data (alerts, alert history)
- Returns success message

### 4. `app/api/user/alerts/history/route.js` (GET)
- Protected route
- Query params: page (default 1), limit (default 20)
- Returns paginated alert history for authenticated user
- Fields: productName, winScore, channel, sentAt, delivered

### 5. `app/api/user/apikey/route.js` (POST for pro users)
- Protected route
- Generates new API key for pro/business users
- Returns: { apiKey: "trendspy_live_xxxxxxxxxxxx" }
