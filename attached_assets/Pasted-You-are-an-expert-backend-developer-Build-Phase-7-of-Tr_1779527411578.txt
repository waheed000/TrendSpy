## Phase 7 Goal: Alert System (WhatsApp via Green API + Email)

Implement a complete alert system that notifies users via WhatsApp and Email when a product meets their criteria (city, category, minWinScore).

## Packages to Install:
- nodemailer

## Files to Create:

### 1. services/whatsappService.js
Create a service that:
- Reads GREEN_API_INSTANCE_ID and GREEN_API_TOKEN from environment variables
- If missing, throws clear error: "❌ GREEN_API_INSTANCE_ID and GREEN_API_TOKEN required. Get from https://green-api.com"
- Sends WhatsApp message using Green API:
  - URL: `https://api.green-api.com/waInstance{GREEN_API_INSTANCE_ID}/sendMessage/{GREEN_API_TOKEN}`
  - Method: POST
  - Body: { chatId: `${phoneNumber}@c.us`, message: formattedMessage }
- Message format:
🚀 TRENDSPY ALERT!

Product: {productName}
Win Score: {winScore}/100 ⭐
City: {city}
Category: {category}
Price: Rs. {priceMin} - Rs. {priceMax}

View full report: {FRONTEND_URL}/products/{slug}

text
- Export: `sendWhatsAppAlert(phoneNumber, product)`

### 2. services/emailService.js
Create a service that:
- Uses nodemailer with Gmail SMTP
- Reads EMAIL_USER and EMAIL_PASS from environment variables
- Email template includes:
  - Product name and image
  - Win Score with color-coded badge
  - Price range in PKR
  - City and category
  - Call-to-action button: "View Product Details"
- Export: `sendEmailAlert(userEmail, product)`

### 3. services/alertService.js
Create a service that:
- Checks all active alerts against a given product
- Matches based on: city, category, and product.winScore >= alert.minWinScore
- For each matching alert:
  - If channel is 'email' or 'both': calls sendEmailAlert(alert.user.email, product)
  - If channel is 'whatsapp' or 'both': calls sendWhatsAppAlert(alert.user.phoneNumber, product)
  - Updates alert.lastTriggeredAt and alert.triggerCount
- Export: `checkAndTriggerAlerts(product)`
- Export: `checkAllProductsForAlerts()` - finds all products with winScore >= 75 and checks alerts

### 4. app/api/alerts/route.js (GET + POST)
- GET (protected): Returns all alerts for authenticated user (populate user details)
- POST (protected): Creates new alert
  - Body: { city, category, minWinScore, channel }
  - channel values: 'email', 'whatsapp', 'both'
  - Validation: city from cityList, category from categories, minWinScore 0-100
  - User must have phoneNumber in profile if channel includes 'whatsapp'
  - Saves to Alert collection

### 5. app/api/alerts/[id]/route.js (DELETE + PUT)
- DELETE (protected): Deletes an alert by ID (user can only delete own alerts)
- PUT (protected): Toggles alert.isActive status

### 6. app/api/alerts/test/route.js (POST)
- Protected route for testing
- Body: { productId }
- Manually calls checkAndTriggerAlerts for that product
- Returns: { triggered: number, alerts: [...] }

### 7. jobs/alertJob.js
Create a cron job that:
- Runs every 30 minutes
- Calls checkAllProductsForAlerts()
- Logs: "Alert job completed. Sent X WhatsApp, Y Email messages."
- Handles errors gracefully (one failure doesn't stop others)
- Export: `startAlertJob()`
