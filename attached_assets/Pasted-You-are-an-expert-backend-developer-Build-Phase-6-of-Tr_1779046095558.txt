## Phase 6 Goal: Win Score Calculation Engine + Cron Jobs

Implement the automated Win Score calculation service and cron jobs to run scrapers and score updates on schedule.

## Packages to Install:
- node-cron

## Files to Create:

### 1. services/winScoreService.js
Create a service that calculates Win Score (0-100) for a product using this formula:

| Signal | Weight | Source |
|--------|--------|--------|
| Daraz sales velocity | 20 | darazOrders / maxOrders in category |
| Google Trends spike | 15 | googleTrendSpike (% increase) |
| Facebook active ads | 20 | activeAds (30+ days running = higher score) |
| Social engagement | 15 | tiktokViews + instagramMentions |
| OLX marketplace demand | 10 | olxViews + olxListings |
| Alibaba order surge | 10 | alibabaOrderSurge |
| Seasonal relevance | 10 | seasonalRelevance (0-100 from seasonalService) |

**Scoring logic:**
- Normalize each signal to 0-100 scale
- Apply weights
- Cap at 100
- If product is new (no data), default score = 30

Export functions:
- `calculateWinScore(product)` – calculates score for single product
- `updateAllWinScores()` – iterates all products and updates winScore field
- `getWinningProducts(city, category, minScore)` – returns products with score >= minScore (default 75)

### 2. services/seasonalService.js
Create a service that:
- Detects current season based on date
- Returns seasonalRelevance score (0-100) for a product category
- Maintains seasonal calendar with date ranges:
  - Ramadan: March-April (2025 dates)
  - Eid ul Fitr: follows Ramadan
  - Eid ul Adha: June
  - Wedding season: November-February
  - Winter: November-February
  - Summer: May-August
  - Back to School: August-September
- Export: `getCurrentSeason()`, `getSeasonalRelevance(category)`, `getUpcomingSeason(days)`

### 3. jobs/scrapeJob.js
Create a cron job that runs every 6 hours:
- Runs: darazScraper, olxScraper, tiktokScraper
- Logs start and end times with timestamps
- If a scraper fails, log error and continue with next
- Export: `startScrapeJob()`

### 4. jobs/trendJob.js
Create a cron job that runs every 12 hours:
- Runs: googleTrendsScraper, newsScraper

- Export: `startTrendJob()`

### 5. jobs/scoreJob.js
Create a cron job that runs every 1 hour:
- Calls updateAllWinScores()
- After scores updated, logs: "Found X products with winScore >= 75"
- Export: `startScoreJob()`

8. lib/scheduler.js
Initialize and start all cron jobs (only if CRON_ENABLED=true):

javascript
import cron from 'node-cron';
import { startScrapeJob, startTrendJob, startScoreJob, startFbAdsJob } from '@/jobs';

export function startAllJobs() {
  // Only schedule if enabled
  if (process.env.CRON_ENABLED !== 'true') {
    console.log('⏸️ Cron jobs disabled. Set CRON_ENABLED=true to enable.');
    return;
  }
  
  // Every 6 hours: 0 */6 * * *
  startScrapeJob();
  
  // Every 12 hours: 0 */12 * * *
  startTrendJob();
  startFbAdsJob();
  
  // Every 1 hour: 0 * * * *
  startScoreJob();
  
  console.log('✅ All cron jobs scheduled');
}
