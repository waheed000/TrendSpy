## Components Details

- **ProductCard**: accepts props (product object). Shows image, name, WinScoreBadge, price range, trend, platforms, and a button to open AIReportModal. Use Tailwind card styling with hover effects.
- **WinScoreBadge**: component that receives score and returns colored badge with text.
- **TrendChart**: Recharts line chart with props for data.
- **HeatMap**: uses Leaflet and geoJson – create a simple mock heatmap layer showing city intensity.
- **AIReportModal**: modal dialog (using a simple div overlay or a library like react-modal). Shows AI report content.
- **FilterBar**: dropdowns for city, category, min score, plus reset button.
- **SeasonalBanner**: shows upcoming event and countdown (e.g., "Ramadan starts in 12 days").
- **AlertBell**: icon with notification count badge (mock unread count 3).
